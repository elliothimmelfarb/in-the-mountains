# Glossary

The milspeak used in the game and the code.

| Term | Meaning |
|---|---|
| **ACM** | Anti-Coalition Militia — the catch-all enemy faction. |
| **TIC** | Troops In Contact — a firefight in progress. |
| **COP / FOB** | Combat Outpost / Forward Operating Base — your base. |
| **OP** | Observation Post. |
| **QRF** | Quick Reaction Force. |
| **CASEVAC / MEDEVAC** | Casualty / medical evacuation (the latter on a dedicated medical bird, often via a 9-line request). |
| **KLE / Shura** | Key Leader Engagement; a council/meeting with village elders. |
| **CERP** | Commander's Emergency Response Program — reconstruction/goodwill funds. |
| **Solatia** | Condolence payment after harm to civilians or property. |
| **Defilade / Dead ground** | Ground hidden from observation and direct fire by terrain. |
| **Draw / Re-entrant** | A gully cutting into a slope — a natural avenue of approach and ambush site. |
| **Spur / Finger** | High ground projecting out from a hillside. |
| **Danger Close** | Friendly troops near enough to a fire mission to be at risk from it. |
| **ICOM** | The enemy's handheld radios; the source of much SIGINT chatter. |
| **SIGINT / HUMINT / ISR** | Signals / human intelligence; Intelligence, Surveillance, Reconnaissance (drones). |
| **ANA / ANP** | Afghan National Army / Police — partner forces. |
| **HIG** | Hezb-e Islami Gulbuddin — one of the insurgent factions of the era. |
| **Base of fire / Maneuver** | Fix the enemy with fire from one element while another moves on him. |
| **Bound / Bounding** | Moving in alternating rushes, one element covering while another advances. |
| **Shoot and scoot** | Fire from a position, then displace before counter-fire arrives. |
| **Pattern of life / Atmospherics** | The normal rhythm of a village; its sudden absence warns of contact. |
| **Qalat** | A mud-walled Afghan family compound; hard cover and concealment. |
| **NODs / NVGs** | Night-observation devices / night-vision goggles. |
| **SAPI / IOTV / ACH** | Body-armor plate / vest / advanced combat helmet (US protection in the wound model). |
| **MAM** | Military-Age Male — the category logged during a census. |
| **9-line** | The standardized MEDEVAC request format. |
| **Willie Pete** | White phosphorus — smoke/incendiary. |
